# Predictive-Analytics-Using-Historical-Data

## Project Overview
This project focuses on predictive analytics using historical Bitcoin data in Power BI. Historical trends are analyzed to understand patterns and forecast future values.

## Objective
To analyze historical Bitcoin data and predict future trends using forecasting techniques.

## Dataset Used
- Bitcoin Historical Dataset
- Features used:
  - Date
  - Close Price
  - Volume BTC
  - High
  - Low

## Tools Used
- Power BI
- Excel/CSV Dataset

## Steps Performed
1. Imported historical Bitcoin dataset
2. Cleaned and preprocessed data
3. Created visualizations
4. Applied forecasting for prediction
5. Analyzed trends and patterns

## Dashboard Visuals
- Line Chart – Bitcoin Price Trend with Forecast
- Card – Average Bitcoin Price
- Card – Total BTC Volume
- Bar Chart – Bitcoin Trading Volume Trend
- Column Chart – High vs Low Price Analysis
- Date Slicer

## Outcome
Successfully analyzed historical Bitcoin data and visualized future trend predictions using Power BI.
